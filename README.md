# Узнаю дорогу.рф

Сайд-проект к кейсу «Знаю дорогу» — карта элементов улично-дорожной сети
Томска (улицы, проспекты, тракты, переулки, площади, микрорайоны и т.д.) с
историей и ссылками, собранными из [towiki.ru](https://towiki.ru).

Полностью статический React-сайт, без бэкенда:

- Список названий по категориям и текст статей (история, ссылки, фото)
  запрашиваются прямо из браузера через публичный MediaWiki API towiki.ru
  (`action=query`/`action=parse`, `origin=*` — CORS открыт).
- Геометрия улиц/топонимов на карте — статический файл
  [`public/data/osm-streets.json`](public/data/osm-streets.json),
  собранный из Overpass API (см. ниже). Overpass не вызывается в рантайме:
  так демо не зависит от его аптайма и рейт-лимитов.
- Карта — Leaflet + стандартные тайлы OpenStreetMap.
- Клик по улице в статье towiki перехватывается и ведёт по приложению
  (карта долетает до объекта, справа открывается его карточка), а не уводит
  на towiki.ru.

## Разработка

```bash
npm install
npm run dev
```

## Пересборка датасета OSM

`public/data/osm-streets.json` — сгенерированный файл. Чтобы обновить его
свежим Overpass-запросом по Томску:

```bash
curl -s -o scripts/overpass-raw.json --data-urlencode "data=$(Get-Content scripts/overpass-query.txt -Raw)" \
  https://maps.mail.ru/osm/tools/overpass/api/interpreter
npm run build:osm-data
```

(`overpass-api.de` из некоторых сетей отдаёт 406/блокирует запросы —
`https://maps.mail.ru/osm/tools/overpass/api/interpreter` в качестве
рабочей альтернативы.)

## Деплой

GitHub Actions ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml))
собирает `npm run build` и публикует `dist/` через GitHub Pages при пуше в
`main`. Требуется один раз включить в настройках репозитория **Settings →
Pages → Source: GitHub Actions**. Домен закреплён файлом
[`public/CNAME`](public/CNAME) (punycode для узнаюдорогу.рф).

## Известные ограничения (2-часовой хакатон)

- Сопоставление названий towiki ↔ OSM — по нормализованному имени с
  единственным эвристическим фолбэком (перестановка первых двух слов).
  Часть объектов (особенно из раздела «Площади» и старая/экзотическая
  топонимика) в OSM просто не размечена — такие карточки показывают статус
  «Нет на карте», это ожидаемо.
- Фильтр служебных страниц внутри категорий towiki (списки, подкатегории,
  переименования) — эвристический, по ключевым словам в заголовке.
